# Технічне завдання

**Проєкт:** веб-сайт «Смак Традиції» — рецепти української кухні
**Виконавець:** Семчук Богдан
**Варіант:** 12 — «Рецепти української кухні»
**Основна сутність:** рецепт
**Обов'язкова функція:** перерахунок інгредієнтів на кількість порцій

---

## 1. Призначення та мета

**Призначення.** Сайт є каталогом рецептів традиційних українських страв із покроковими
інструкціями та калькулятором інгредієнтів, який автоматично перераховує кількість
продуктів під потрібну кількість порцій.

**Мета.** Дати змогу швидко знайти рецепт української страви за категорією, регіоном
чи назвою та приготувати її рівно на стільки людей, скільки потрібно, без ручних
підрахунків.

**Цільова аудиторія:**
- молоді люди 18–30 років, які лише вчаться готувати і хочуть зрозумілих рецептів;
- господині й господарі 30–55 років, які готують для сім'ї або свят на різну кількість гостей;
- українці за кордоном, які хочуть відтворити страви домашньої кухні.

**Ключові сценарії використання:**
1. Користувач шукає рецепт за назвою (наприклад, «вареники») або фільтрує каталог
   за категорією та часом приготування, відкриває рецепт.
2. Користувач на сторінці рецепта змінює кількість порцій з 4 на 10, і всі інгредієнти
   перераховуються автоматично.
3. Користувач додає власний сімейний рецепт через форму, а сайт перевіряє коректність
   заповнення.

## 3. Структура сторінок (карта сайту)

```
/                       Головна
├── /recipes            Каталог рецептів (пошук, фільтри, сортування)
│   └── /recipes/:id    Сторінка рецепта (калькулятор порцій, кроки)
├── /recipes/new        Форма «Додати рецепт»
├── /contacts           Контакти та форма зворотного зв'язку
└── *                   Сторінка 404
```

Шапка (логотип, меню, перемикач теми) і футер присутні на всіх сторінках.

## 7. Структура даних

### Рецепт (Recipe)

| Поле | Тип | Опис |
|---|---|---|
| id | string | Унікальний ідентифікатор |
| title | string | Назва страви (3–100 символів) |

| region | string | Регіон походження (наприклад, «Полтавщина») |

## 8. Алгоритм перерахунку порцій

```
нова кількість = базова кількість × (нові порції / базові порції)
```

Правила округлення:
- `г`, `мл` — до цілого; якщо більше 100, то до 5;
- `кг`, `л` — до 0,1;
- `шт`, `зубчик` — до 0,5, але не менше 0,5 (не можна взяти 0 яєць);
- `ст. л.`, `ч. л.` — до 0,5;
- «за смаком» — не перераховується.

Кількість порцій обмежено діапазоном 1–20.

## 9. Взаємодія клієнта і сервера

React-клієнт надсилає HTTP-запити до REST API на Express (адреса — у змінній `VITE_API_URL`),
сервер повертає дані у форматі JSON.

| Метод | Шлях | Призначення |
|---|---|---|
| GET | /api/recipes | Список рецептів (параметри `q`, `category`, `region`, `sort`) |
| GET | /api/recipes/:id | Один рецепт |
| POST | /api/recipes | Створення рецепта (валідація, 201 / 400) |
| PUT | /api/recipes/:id | Оновлення рецепта |
| DELETE | /api/recipes/:id | Видалення рецепта (204) |
| POST | /api/contact | Повідомлення зворотного зв'язку (201 / 400) |

Перерахунок порцій виконується на клієнті, бо це чисті обчислення без звернення до сервера.
