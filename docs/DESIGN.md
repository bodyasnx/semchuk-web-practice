# Дизайн-система «Смак Традиції»

**Практична робота:** ПР 3 «Дизайн-система»
**Інструменти:** Figma не використовується (погоджено з викладачем). Мудборд — добірка
референсів з Pinterest (лише посилання), макети компонентів — HTML-сторінка
[design-system.html](design-system.html).

> Проєкт — **один адаптивний вебсайт (mobile-first)**, а не окремий мобільний застосунок.
> Мобільні референси використано лише як ідеї для адаптації того самого сайту під ширину 360–768 px.

## 1. Мудборд: референси

Зображення з Pinterest **не копіюються в репозиторій** — вони захищені авторським правом
їхніх авторів. Тут лише посилання і те, яку ідею з кожного референса взято. Макет, фото
й ілюстрації не відтворюються — запозичується тільки загальний настрій і принципи.

«Не позначено» означає, що в описі завдання цей пін не вказано як AI-зображення; перед

**Напрям стилю:** «сучасна українська кухня» — темно-зелений як основний колір (зелень,
городина, ліс), тепле золото як акцент (пшениця, хліб, мед), кремовий фон світлої теми
(полотно, борошно), червоний мотив вишиванки — лише як декор. Темна тема — глибокий
зелений замість чорного.

Кольори задаються як дизайн-токени (CSS custom properties) і мають значення для обох тем.

### 2.6. Правила використання кольору

1. Світле золото `#C8962E` на кремовому фоні має лише **2,48:1**, тому в світлій темі воно
   не використовується для тексту, меж полів чи значків, що несуть зміст. Тільки декор
   (орнамент, розділювач) і фон під темним текстом (5,83:1). Для золотого тексту є
   `--color-accent-text` `#7D5A10` (5,83:1).
2. Червоний `--color-ornament` — тільки для орнаменту. Для помилок є окремий `--color-error`,
   щоб декоративний червоний не сприймався як «щось зламалося».
3. Рамка фокусу малюється з відступом (`outline-offset: 2px`), тобто на фоні сторінки,
   а не на кнопці: так у темній темі золота рамка видна навіть навколо золотої кнопки.
4. Неактивні (disabled) елементи мають знижений контраст (3,89 і 4,24). Це допустимо:
   WCAG 1.4.3 не поширюється на неактивні компоненти інтерфейсу.

## 3. Перевірка контрасту WCAG 2.1 AA

**Як пораховано.** Скриптом на Node.js за формулою WCAG 2.x: для кожного кольору
обчислюється відносна яскравість `L = 0,2126·R + 0,7152·G + 0,0722·B` (канали
лінеаризовані з sRGB), контраст = `(L₁ + 0,05) / (L₂ + 0,05)`, де L₁ — світліший колір.
Значення округлено до сотих. На сторінці [design-system.html](design-system.html)
контраст основних пар перераховується наживо для поточної теми.

**Пороги:** звичайний текст — **4,5:1**; великий текст (від 24 px, або від 18,66 px
жирним) і нетекстові елементи (межі полів, значки, рамка фокусу) — **3:1**;
суто декоративні елементи — без вимог.

## 4. Типографіка

| Роль | Шрифт | Накреслення | Чому |
|---|---|---|---|
| Заголовки | [Lora](https://fonts.google.com/specimen/Lora) (з засічками) | 600, 700 | Теплий «книжний» характер — як у збірці рецептів; повна кирилиця з ґ, є, і, ї |
| Текст | [Manrope](https://fonts.google.com/specimen/Manrope) (гротеск) | 400, 600, 700 | Добре читається на малих розмірах і екранах телефонів; кирилиця |

Обидва шрифти — Google Fonts під ліцензією SIL Open Font License (можна вільно
використовувати на сайті). Підключаються з `display=swap`: поки шрифт завантажується,
текст показано системним шрифтом, а не порожнечею.

**Шкала** плавно змінюється між шириною 360 px і 1280 px через `clamp()`:

| Рівень | Токен | 360 px | 1280 px | Інтерліньяж |
|---|---|---|---|---|
| H1 | `--text-h1` = `clamp(2rem, 1.609rem + 1.739vw, 3rem)` | 32 px | 48 px | 1,2 |
| H2 | `--text-h2` = `clamp(1.625rem, 1.38rem + 1.087vw, 2.25rem)` | 26 px | 36 px | 1,2 |
| H3 | `--text-h3` = `clamp(1.25rem, 1.152rem + 0.435vw, 1.5rem)` | 20 px | 24 px | 1,2 |
| H4 | `--text-h4` = `clamp(1.125rem, 1.076rem + 0.217vw, 1.25rem)` | 18 px | 20 px | 1,2 |
| Body | `--text-body` = `clamp(1rem, 0.951rem + 0.217vw, 1.125rem)` | 16 px | 18 px | 1,6 |
| Small | `--text-small` = `0.875rem` | 14 px | 14 px | 1,5 |

`clamp(мінімум, бажане, максимум)`: бажане значення складається з `rem` (поважає
налаштування розміру шрифту в браузері) і `vw` (росте з шириною екрана), а мінімум і
максимум не дають тексту стати надто дрібним чи завеликим. Довжина рядка обмежена
70 символами (`max-width: 70ch`) для зручного читання.

## 5. Токени

Файли: [client/styles/tokens.css](../client/styles/tokens.css) — усі токени,
[client/styles/typography.css](../client/styles/typography.css) — базові стилі тексту.

| Група | Токени | Значення |
|---|---|---|
| Відступи | `--space-1` … `--space-6` | 4, 8, 16, 24, 32, 48 px (у `rem`) |
| Радіуси | `--radius-sm`, `-md`, `-lg`, `-pill` | 4, 8, 16, 999 px |
| Тіні | `--shadow-sm`, `-md`, `-lg` | у темній темі темніші й щільніші |
| Шрифти | `--font-heading`, `--font-body` | Lora, Manrope + системні запасні |
| Розміри | `--size-touch` | 44 px — мінімальна ціль для пальця |
| Анімація | `--duration-fast`, `--duration-base`, `--ease-standard` | 150 мс, 250 мс |

**Як працює тема.** У `:root` записано значення світлої теми. Темна тема перевизначає
лише кольори і тіні — двічі:
1. `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { … } }` —
   якщо в системі темна тема і користувач не обрав світлу вручну;
2. `:root[data-theme="dark"] { … }` — якщо користувач обрав темну перемикачем.

Компоненти використовують лише токени (`background: var(--color-surface)`), тому
перемикання теми не потребує жодних змін у їхньому CSS.
