# Семантична HTML5-розмітка

**Практична робота:** ПР 4 «Семантична HTML5-розмітка»
**Файли:** [client/static/](../client/static/) — 6 сторінок без стилів (стилі — ПР 5, JS — ПР 6).
Відкриваються подвійним кліком, сервер не потрібен.

## 1. Сторінки

| Файл | h1 | Призначення | Ключові елементи |
|---|---|---|---|
| `index.html` | Рецепти української кухні | Головна: пошук, категорії, популярні рецепти, пояснення калькулятора | `header`, `nav`, `main`, `section` ×4, `article` ×4, `aside`, `figure` + `figcaption` (таблиця-приклад), `footer`, `address`, `time` |
| `recipes.html` | Каталог рецептів | Каталог: пошук, фільтри, сортування, 10 рецептів | `nav` (хлібні крихти), `aside` (фільтри), `section`, `article` ×10, `dl`, `fieldset`/`legend` |
| `recipe.html` | Український борщ | Сторінка рецепта з перемикачем порцій | `article` з власними `header`/`footer`, `figure` + `figcaption`, `ul` (інгредієнти), `ol` (кроки), `data`, `time datetime="PT2H"`, `aside`, JSON-LD `Recipe` |
| `404.html` | Сторінку не знайдено | Помилка 404 з петриківкою і посиланнями | `main`, `meta robots noindex` |
| `add-recipe.html` | Додати рецепт | Форма нового рецепта з HTML-валідацією | `form`, вкладені `fieldset`/`legend`, `abbr` для позначки «*» |
| `contacts.html` | Контакти | Контакти, форма зворотного зв'язку, мапа | `address`, `form`, `iframe` OpenStreetMap з `title` |

**Спільне на всіх сторінках:**
- `<html lang="uk">`, `meta charset`, `meta viewport`;
- унікальні `<title>` і `meta description`, Open Graph (`og:type`, `og:title`, `og:description`,
  `og:url`, `og:image`, `og:locale`), favicon `../assets/logo-mark.svg`;
- посилання «Перейти до основного вмісту» (`#main`) для користувачів клавіатури;
- рівно один `h1`, заголовки без пропусків рівнів (перевірено скриптом);
- поточна сторінка в меню позначена `aria-current="page"`.

│   │   ├── h2 Популярні рецепти               (section)
│   │   │   ├── h3 Український борщ            (article: picture, dl з регіоном, часом, складністю)
│   │   │   ├── h3 Вареники з картоплею        (article)
│   │   │   ├── h3 Деруни                      (article)

## 3. Семантичні рішення

| Що | Як розмічено | Чому |
|---|---|---|
| Характеристики рецепта | `dl` / `dt` / `dd` | Пари «назва — значення» (Регіон — Полтавщина) |
| Час приготування | `<time datetime="PT2H">2 год</time>` | Машиночитаний формат тривалості ISO 8601 для пошукових систем |
| Кількість інгредієнта | `<data value="300" data-unit="г">300</data>` | Число для перерахунку порцій у ПР 6 окремо від тексту |
| Перемикач порцій | `label` + `button type="button"` −/+ + `input type="number" min="1" max="20"` | Працює з клавіатури; межі 1–20 задано в розмітці |
| Інгредієнти / кроки | `ul` / `ol` | Порядок інгредієнтів не важливий, порядок кроків — важливий |
| Бейдж регіону | `img alt=""` + текст | Значок декоративний, назву регіону читає текст |
| Рецепт для пошуковиків | JSON-LD `schema.org/Recipe` | Розширений сніпет у Google (час, інгредієнти, кроки) |
| Хлібні крихти | `nav aria-label` + `ol`, остання ланка `aria-current="page"` | Скрінрідер оголошує «навігація, хлібні крихти» |

## 4. Адаптивні зображення

```html
<picture>
  <source type="image/webp"
          srcset="images/recipes/borshch-480.webp 480w, images/recipes/borshch-800.webp 800w, images/recipes/borshch-1200.webp 1200w"
          sizes="(min-width: 1280px) 290px, (min-width: 768px) 45vw, 100vw">
  <img src="images/recipes/borshch-800.jpg" alt="Тарілка червоного борщу зі сметаною і зеленню"
       width="800" height="600" loading="lazy" decoding="async">
</picture>
```

| Місце | `sizes` | Завантаження |
|---|---|---|
| Фото першого екрана на головній | `(min-width: 768px) 50vw, 100vw` | одразу, `fetchpriority="high"` |
| Картки на головній | `(min-width: 1280px) 280px, (min-width: 768px) 45vw, 100vw` | `loading="lazy"` |
| Картки в каталозі | `(min-width: 1280px) 290px, (min-width: 768px) 45vw, 100vw` | перша — одразу, решта — `lazy` |
| Фото на сторінці рецепта | `(min-width: 1280px) 700px, 100vw` | одразу, `fetchpriority="high"` |

`width`/`height` на кожному `img` резервують місце до завантаження — сторінка не «стрибає»
(метрика CLS). Значення `sizes` орієнтовні й будуть уточнені під сітку в ПР 5.

**Фото поки — тимчасові заглушки**, справжні фото з Unsplash/Pexels буде додано з тими самими
іменами файлів, тож розмітка не зміниться. Джерела — у [CREDITS.md](CREDITS.md).

## 5. Форми

| Тип поля | Де | Валідація |
|---|---|---|
| `text` | назва страви, інгредієнти, ім'я | `required`, `minlength`, `maxlength` |
| `email` | контакти | `required`, перевірка формату браузером |
| `tel` | контакти | `pattern="\+380[0-9]{9}"` — лише `+380XXXXXXXXX` |
| `number` | порції, час, кількість інгредієнта | `min`/`max`/`step` (порції 1–20) |
| `select` | категорія, регіон, одиниця, тема | `required` з порожнім першим варіантом |
| `textarea` | опис, кроки, повідомлення | `minlength`/`maxlength` (повідомлення 10–1000) |
| `checkbox` | згода, розсилка, фільтри | `required` для згоди |
| `radio` | складність, час у фільтрах | `required` на групі |

Кожне поле має `label for`, групи — `fieldset` + `legend`, підказки прив'язані
через `aria-describedby`, обов'язкові поля позначені `<abbr title="обов'язкове поле">*</abbr>`
і атрибутом `required`. Це перша лінія перевірки; валідація на JS (ПР 6) і на сервері
(ПР 8) буде додана пізніше.

## 6. Перевірка валідності

Перевірено локально офіційним валідатором W3C **Nu Html Checker** (`vnu.jar` 24.10.17 —
той самий рушій, що на validator.w3.org):

| Файл | Помилки | Попередження |
|---|---|---|
| `index.html`, `recipes.html`, `recipe.html`, `404.html`, `add-recipe.html`, `contacts.html` | 0 | 0 |
| `client/assets/*.svg` (10 файлів, режим `--also-check-svg`) | 0 | 0 |

**Що виправлено під час перевірки:**
- `inputmode="numeric"` на `input type="number"` — зайвий (цифрова клавіатура і так
  з'являється), прибрано зі сторінки рецепта і з `docs/design-system.html`;
- у 10 SVG-файлах з ПР 3 на кореневому `<svg>` були `aria-label` / `aria-hidden` —
  схема SVG 1.1 їх не дозволяє, а у файлах, вставлених через `<img>`, вони все одно
  ігноруються (назву дає `<title>` у файлі та `alt` на сторінці). Атрибути прибрано.

## 7. Примітки

- **Регіони** прив'язано до найвідомішого осередку страви; багато страв (борщ, вареники,
  деруни) — загальноукраїнські.
- **Домен** в `og:url` / `og:image` — тимчасовий `smak-tradytsii.example`, буде замінено
  на справжню адресу під час деплою (ПР 10).
- **Контакти** (пошта, телефон) — демонстраційні, не справжні.
- `404.html` використовує відносні шляхи; на сервері в ПР 8–10 їх буде замінено на
  абсолютні (`/assets/...`), бо 404 може відкритися за будь-якою адресою.
